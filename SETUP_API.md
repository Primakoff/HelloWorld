# Подключение API Etherscan (сделать завтра, ~10 минут)

## Что это и зачем

Сейчас транзакции смотрятся глазами в Etherscan/Arkham и передаются Claude скриншотами:
видно 10–20 строк за раз и только то, что попало в кадр.

**API** — это вход на тот же Etherscan, но для программ. Скрипт сам спрашивает «дай все
транзакции этого адреса во всех сетях» и получает таблицу с тысячами строк. Так можно
пройти весь путь денег, посчитать общий объём украденного и найти всех жертв.

**Ключ API** — как читательский билет: показывает Etherscan, кто спрашивает. Бесплатный и
**только для чтения**: смотреть публичный блокчейн можно, тронуть кошелёк или деньги нельзя.

**Почему Claude не может сделать это сам:** у облачного компьютера Claude есть список
разрешённых сайтов, Etherscan в нём нет. Добавить сайт и положить ключ можете только вы.

## Шаг 1. Получить ключ (5 минут)

1. **etherscan.io** → **Sign Up** → почта и пароль → подтвердить почту.
2. Войти → нажать на свой ник справа вверху → **API Keys**.
3. **+ Add** → имя, например, `investigation` → **Create**.
4. Скопировать ключ (строка примерно из 34 букв и цифр).

## Шаг 2. Открыть доступ и сохранить ключ (3 минуты)

1. claude.ai/code → в верхней панели сессии нажать на название окружения (иконка облака) → **Edit**.
2. **Network access** → **Allowed domains** → добавить `api.etherscan.io`.
   Галочку **Allow package managers** не снимать.
3. Раздел **Network secrets** (в старой версии приложения: **API credentials** или
   **Environment variables**):
   - имя: `ETHERSCAN_API_KEY`
   - значение: ваш ключ
4. **Save**.

Инструкция Anthropic: https://code.claude.com/docs/en/cloud-environments#network-access

## Шаг 3. Новая сессия

Настройки применяются только к **новым** сессиям. Открыть новую сессию с репозиторием
`Primakoff/HelloWorld`, ветка `claude/hacker-tracking-stolen-funds-ik7ngl`, и вставить:

> Ключ Etherscan добавлен. Прочитай README.md, SETUP_API.md, learning/ROADMAP.md и
> case/addresses.csv. Запусти `python3 tracer/run_case.py`, разбери отчёты в case/reports/
> и обнови гипотезы: 0x0699 (жертва или хакер?), 0xb68db, 0xCFE9D, 0x03BEF (кошельки хакера?),
> куда ушли 61K/45K/26K в стейблкоинах, кто прислал газ на мой адрес в Optimism перед
> кражей OP. Потом сопоставь депозиты в ChangeNOW (tracer/match_swaps.py).
> Объясняй каждый шаг: я учусь на этом кейсе (learning/ROADMAP.md, месяц 1).

## Важно

- **Ключ не присылать в чат и не класть в файлы репозитория.** Место для него — только
  настройки окружения. Если засветился, удалить на etherscan.io и создать новый (бесплатно).
- **Бесплатный тариф может не покрывать часть сетей** (в 2025 году из бесплатного доступа
  убирали BNB Chain, Base, Optimism, Avalanche; могло измениться). Ethereum и Arbitrum,
  где лежат главные транзакции дела, обычно доступны. Скрипт сообщит, какая сеть не ответила;
  для неё используем CSV-выгрузку из Arkham.
- Не получается — скриншот экрана настроек (без ключа) в чат, Claude подскажет, куда нажать.
